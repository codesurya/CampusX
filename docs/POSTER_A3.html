🎯 Problem Statement & Objectives

University students face fragmented communication, anxiety over the mandatory 75% attendance threshold, unorganized lecture notes, and no verified campus exchange for course gear.

  • Zero-Fragmentation: Single portal uniting timetable, circulars & study materials.
  • Mathematical Precision: Algorithmic prediction of attendance shortfall/surplus.
  • Student Economy: Peer-to-peer textbook & instrument marketplace.
  • Offline Knowledge AI: Fast automated answers to campus FAQs and schedules.

📊 75% Attendance Mathematical Model

Let $a = \text{attended classes}$ and $t = \text{total classes conducted}$. Attendance percentage is $P = (a/t) \times 100$.

Deficit Condition (P < 75%):
Classes required to attend consecutively without absence:
Required Classes = max(0, ⌈3t - 4a⌉)
Surplus Condition (P ≥ 75%):
Lectures that can be safely skipped while staying ≥75%:
Safe Skips = max(0, ⌊4a/3 - t⌋)

✓ Instant visual risk alerts (Green ≥85%, Blue 75–84%, Amber <75%).

Enforces strict tenant data isolation: user records strictly query by { user: req.user.id }, preventing horizontal privilege escalation.

📅 Academic Timetable & Notices

Smart Class Routine Scheduler Day-wise timetable (Mon–Sun) with automated current-day detection ($today = (JS_{day} + 6) \bmod 7$), faculty names, room/lab numbers, and strict $T_{start} < T_{end}$ validation.
College Notices & Circulars Board Categorized into Exam, Holiday, Academic, General, and Fest. Features high-priority red alert tags and instant multi-keyword search.

📚 Peer-to-Peer Academic Utilities

NotesHub Academic Repository Subject-wise verified handwritten notes, syllabus PPTs, and solved question banks categorized by Subject (DSA, OS, DBMS, Networks, Cloud) with download counters.
Campus Marketplace (Zero-Commission) Student-to-student exchange for engineering textbooks, mini-drafters, Casio scientific calculators, and bicycles with in-app seller contact information.
Centralized Lost & Found Desk Report lost and recovered university ID cards, keys, and tech gear with location tags and one-click 'Mark Returned' status tracking.

🚀 Campus Life & Student Societies

Clubs & Communities Hub Directory of recognized student bodies (Google Developer Club, RoboX, Dhwani Music, E-Cell, Rotaract) with 1-click Join/Leave club toggles and schedules.
Campus Events & Fests Calendar Interactive event portal with live attendee headcount tracking and 1-click RSVP for technical hackathons, workshops, and cultural galas.

🤖 AI Campus Assistant Engine

An offline-first, dynamic campus knowledge engine providing instant contextual assistance without dependency on external paid APIs:

  • Dynamic Attendance Diagnostics: Reads MongoDB records on command and outputs live subject percentages.
  • Live Schedule Lookup: Interrogates today's lecture slots, venues, and instructors.
  • Campus Regulations FAQ: Instant guidance on 75% debarment rules, library hours, and Wi-Fi configuration.

🛡️ Governance & Security (RBAC)

Standalone Admin Dashboard Protected by adminAuth. Allows authorized faculty/admins to manage student accounts, publish official circulars, and moderate marketplace items.
Role Security & Hardening Public registration strictly locked to student role. Role self-promotion in profile endpoint disabled. Admin creation restricted to secure backend CLI script.
